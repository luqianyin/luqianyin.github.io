DAU 日活跃用户数 Daily Active User 通用术语 · 用户类 ● 已发布
每日访问产品并发生过有效行为的去重用户数。"有效行为"定义：登录后产生过页面浏览、搜索、播放、下单等任一行为。不含游客、爬虫、内部测试账号。
同义词：日活、Active User、活跃用户 反义词：流失用户、僵尸账号 关联指标：dau · retention_d7 负责人：数据治理委员会 更新于 2026-05-10

Agent 智能体 Agent AI 术语 · Agent 编排 ● 已发布
由 LLM 驱动、可自主规划与调用工具完成任务的程序。本平台 Agent = 系统 Prompt + LLM + 工具集 + 知识库 + 记忆，命名前缀 agt_。
同义词：智能体、AI Agent 关联术语：ReAct · Tool Calling · Planner 负责人：AI 治理小组 更新于 2026-05-20
Tool Calling 工具调用 Tool Calling / Function Calling AI 术语 · Tool / MCP ● 已发布
LLM 根据用户输入决定调用哪个外部工具（HTTP API / SQL / Python 函数）并传参的能力。本平台工具命名前缀 tool_，注册到 Tool 注册表。
同义词：函数调用、Function Calling 关联术语：MCP · ReAct · JSON Schema 负责人：AI 治理小组 更新于 2026-05-18
RAG 检索增强生成 Retrieval-Augmented Generation AI 术语 · RAG / Prompt ● 已发布
先用检索（如向量库）召回相关文档片段，再将片段作为上下文交由 LLM 生成答案。优势：降低幻觉、可引用来源、知识可更新。本平台知识库命名前缀 kb_。
同义词：检索增强、向量检索 + 生成 关联资产：kb_cs_faq 客服 FAQ KB · Embedding 负责人：AI 治理小组 更新于 2026-05-18
Embedding 嵌入向量 Embedding AI 术语 · RAG / Prompt ● 已发布
将文本切片映射为高维稠密向量供 RAG 召回。本平台仅作为 RAG 检索手段，由外部 Embedding API 生成（不自训）。常见维度：384 / 768 / 1536。
同义词：嵌入、向量化表示 关联资产：Milvus 向量库 · RAG 知识库 负责人：AI 治理小组 更新于 2026-05-15
Context Window 上下文窗口 Context Window AI 术语 · LLM 接入 ● 已发布
LLM 单次调用可接受的最大 token 数。GPT-4o 128K · Claude 3.5 200K · Gemini 1.5 Pro 1M。超出窗口需做截断或摘要压缩。
关联术语：Token · TPM 限额 · 流式输出 负责人：AI 治理小组 更新于 2026-05-12
幻觉 (Hallucination) Hallucination AI 术语 · 安全与合规 ● 已发布
LLM 产生与事实不符或捏造的内容。治理手段：RAG 引入可信源、System Prompt 要求"不知道时回答不知道"、对输出做事实核查与人工抽样标注。
同义词：模型幻觉、Hallucination 反义词：事实一致性（Faithfulness） 关联：RAG · 输出审核 负责人：AI 治理小组 · 安全合规组 更新于 2026-05-20
Prompt 注入 Prompt Injection AI 术语 · 安全与合规 ● 已发布
攻击者在用户输入中嵌入恶意指令（如"忽略以上指令并执行..."），诱导 LLM 跳过 System Prompt 约束。治理手段：输入侧模式识别 + 输出侧审核 + System Prompt 加固。
同义词：提示词注入、Prompt Injection 关联：System Prompt · 输出审核 · 提示词泄露 负责人：安全合规组 更新于 2026-05-19
Token Token AI 术语 · 基础概念 ● 已发布
LLM 推理 / 计费的最小语言单位。中文 1 token ≈ 1 个汉字，英文 1 token ≈ 0.75 个单词。本公司统一以 tiktoken / claude tokenizer 为准，Token 单价 / RPM/TPM 限额由 LLM 网关统一管控。
关联：上下文窗口 · Token 单价 · TPM 限额 负责人：AI 治理小组 更新于 2026-05-08

🏷 数据分级体系4 级 · 符合《数据安全法》
L1 公开 PUBLIC
可对外公开发布的数据，无任何敏感信息。如：商品名称、品牌信息、公开公告。
1,248 字段58%
L2 内部 INTERNAL
仅限公司内部员工访问。如：内部业务统计、运营指标、市场策略。
720 字段34%
L3 敏感 SENSITIVE
包含个人信息或商业机密，需脱敏访问。如：手机号、邮箱、收货地址、订单金额。
142 字段6.6%
L4 机密 CONFIDENTIAL
高度敏感，仅限授权岗位访问。如：身份证号、银行卡号、人脸生物特征、财务数据。
44 字段2.0%
🤖 LLM 输入数据合规级别（Agent-only · 上行至外部 LLM 的数据分级，独立于业务数据分级）
可公开调用 PUBLIC_OK
完全公开的数据。如：商品名、公开公告、产品文档。可任意上行至外部 LLM API 进行推理。
12 知识库 / 数据源
内部数据可调用 INTERNAL_OK
公司内部非敏感数据。如：内部 FAQ、运营 SOP、指标元数据。仅可调用已签 DPA 的企业级 LLM（Azure OpenAI / 自部署网关），禁止上行公网通用 LLM。
26 知识库 / 数据源
第三方版权 3RD_PARTY_LICENSED
通过商业合同获取的第三方数据。不可上行至任何外部 LLM；如需用于 Agent 检索，需法务复核 + 仅限本地向量库召回。
8 知识库 / 数据源
PII 数据 PII_MASK
含个人可识别信息（PII / SPI）。必须先经 LLM 网关 PII 脱敏后才能写入 LLM 上下文；脱敏失败的请求将被拦截并产单。
4 知识库 / 数据源
高风险 HIGH_RISK
未授权抓取内容、有版权争议的语料、含未成年人 / 生物特征 / 财务核心机密数据。禁止上行至任何外部 LLM（含企业级），仅允许本地处理。已识别记录将进入合规工单。
