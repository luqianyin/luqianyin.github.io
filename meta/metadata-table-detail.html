使用说明

最近更新：2026-04-28 14:22 · 张晓明

📋 表用途

WEDATA.SYSDBA.##HISTOGRAMS_TABLE 是数据库系统内置的列级直方图统计表，存储各表各字段的数据分布信息，查询优化器在生成执行计划时会读取本表来选择代价最优的访问路径。

🎯 使用场景

  • SQL 优化分析：判断查询慢是否由统计信息缺失或过期导致
  • 表健康度监控：识别长期未分析、NDV 异常、桶数过少的字段
  • 容量规划：基于 NDV 估算唯一索引、Bitmap 索引的存储成本

💡 典型查询示例

查询某张表所有字段的最近统计时间：

SELECT
  COLUMN_NAME,
  HISTOGRAM_TYPE,
  NDV,
  BUCKETS_COUNT,
  LAST_ANALYZED
FROM SYSDBA.##HISTOGRAMS_TABLE
WHERE SCHEMA_NAME = 'BUSINESS'
  AND TABLE_NAME  = 'ORDER_HEAD'
ORDER BY LAST_ANALYZED DESC;

⚠️ 使用注意

⚠️ 不要对本表进行 INSERT / UPDATE / DELETE，统计信息由系统自动维护。如需手动重新分析，请调用 DBMS_STATS.GATHER_TABLE_STATS() 存储过程。
  • 本表每日 02:00 由 vcbqv6l7_DM_collect_job 增量采集，约滞后 6 小时
  • NDV 字段是估算值（基于 HyperLogLog），误差率 ≤ 0.5%
  • HISTOGRAM_TYPE 当前支持 EQUI_HEIGHT / FREQUENCY / TOP_K，新增枚举值需提前评审
